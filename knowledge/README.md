# パラスの知識フォルダ

ここに置いた資料を、パラスが調べて答えに使います（RAG）。

## 置き方
- このフォルダ（サブフォルダも可）に、次の形式のファイルを置いて GitHub にアップするだけです。
  - Markdown（`.md`）… 見出し（`#` `##`）ごとに分けて検索されるので、いちばん精度が出ます
  - テキスト（`.txt`）
  - PDF（`.pdf`）… 文字が埋め込まれている PDF のみ（スキャン画像だけの PDF は読めません）
- `main` に取り込まれると、公開の Actions が自動で検索用の索引を作り直します。
- 資料のいちばん上の `# 見出し` が、その資料の名前として使われます。

## 注意
- **GitHub Pages で公開されるので、ここに置いた資料は誰でも読める状態になります。** 社外秘・個人情報は置かないでください。
- 1つの資料が大きすぎると検索の精度が落ちます。章ごとにファイルを分けるか、見出しをしっかり付けるのがおすすめです。
- この README.md 自体は索引に入りません。
