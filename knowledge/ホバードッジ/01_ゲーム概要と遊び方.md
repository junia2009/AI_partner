# HOVER DODGE（ホバードッジ）概要と遊び方

マスターが作ったゲーム「HOVER DODGE」の資料です。元の資料はリポジトリ junia2009/hover-dodge の README と docs/LORE.md。

## どんなゲームか
- キャッチコピーは「宇宙海賊団バイデントを追え」。ネオン・サイバーパンク調の、フラッピーバード系の回避ゲーム。
- タップひとつで遊べる横スクロールのアーケードゲーム。Three.js と WebGL で 3D 描画している。
- ブラウザだけで動き、PWA としてホーム画面に追加すればオフラインでも遊べる。
- 遊ぶ：https://junia2009.github.io/hover-dodge/ （スマホは横向き専用）
- 主な特徴
  - 4 章のストーリー（完結）：小さな鳥のパイロット「レイ」と相棒 AI「パラス」の物語。プロローグ・エピローグ・回想は 3D カットシーンで、LOG から見返せる。
  - ボス戦 11 体：第一部 STYX / ACHERON、第二部 ORTHROS / CHARON / CERBERUS、第三部 THANATOS / HYPNOS / THE GATE、最終章 LETHE / EREBUS / NYX。
  - やり込み：パイロットレベル（最大 Lv80）、スキルツリー、装備枠、HULL（耐久）、シナジー、スキン、9 つの隠し要素。
  - 3D モデル（glTF）と、プレイに合わせて変化する手続き合成の BGM。
- 現在のバージョンは 3.6.6（README 時点）。

## 操作
- タップ / SPACE：自機を上昇させる（重力で落ちる）。FORWARD SHOT 系を装備していれば、タップで前方弾も撃つ。
- PULSE / Z キー：範囲攻撃。周りの敵を一掃し、ボスの大型弾を跳ね返す。
- ESC / P / 一時停止ボタン：一時停止と再開（タブを離れると自動で一時停止）。
- M キー：音をまとめて ON / OFF。BGM と効果音は個別にも切り替えられる。
- カットシーン：タップ / SPACE / ENTER で次へ、SKIP / ESC で飛ばす。

## ゴールとスコア
- スコア＝生き残った秒数（OVERDRIVE 中は 1.5 倍で進む）。ひたすら長く生き残るのが目的。
- 死んだら RETRY ですぐやり直せる。記録・XP・進行はすべて端末に保存される。
- スレスレ通過や撃破のボーナスは XP として入る。
  - 壁スレスレ通過 CLOSE（隙間の中央から外側 30% 以内）：+3 XP
  - 極スレスレ NEAR!（外側 15% 以内）：+8 XP（OVERDRIVE 中は 2 倍）
  - 敵を撃破：+5 XP
  - PULSE を 5 秒以上使わずにいると PURIST 表示

## フェーズ（難易度の段階）
スコアに応じて 4 段階に難しくなり、BGM もそれに合わせて厚くなる。境目では 8 秒かけてなだらかに移行する。

| フェーズ | スコア | 敵 | BGM |
|---|---|---|---|
| 1 | 0〜20 秒 | 壁だけ（練習） | アンビエントのパッドだけ |
| 2 | 20〜50 秒 | プラズマ弾の敵が登場 | ＋ベース＋キック |
| 3 | 50〜100 秒 | 追いかけてくるシーカーが混ざる | ＋リード |
| 4 | 100 秒〜 | 全部の敵、最高速度 | フルミックス |

- 区間名：PHASE 1〜4 ＝ アイギス上空 / バイデント前線 / 監視宙域 / バイデント本拠。
- 壁の隙間は、前の隙間から人間が余裕をもって届く範囲にだけ出る（重力・羽ばたき・速度から毎回計算し、人間の限界の 65% に制限）。運で詰む配置は出ない。

## ボス戦の基本
- ボスが来ると壁と通常の敵が止まり、旗艦が画面右側に陣取る。
- エネルギーコアを 3 つ集めると主砲 AEGIS CANNON が自動で発射される（誰でも倒せる軸）。
- 大型弾を PULSE で跳ね返すと大ダメージ。射撃スキルの弾でも削れる。
- 攻撃は、扇状の弾幕、予告付きレーザー（安全地帯あり）、レーザー掃射、ゲート召喚、追跡機雷、交互射撃、上下からの挟み撃ち、環状弾など。HP が 50% を切ると激しくなる。
- CERBERUS は HP を 3 分の 1 削るごとに首が 1 本ずつ折れる（炎の首＝3 連の扇状弾 → 氷の首＝隙間のある弾の壁 → 闇の首＝跳ね返せない闇の弾。闇の弾は PULSE で消せる）。

## タイトル画面
- STORY / ✈ PILOT：モードの選択（最終章クリア後）。STORY では CHAPTER Ⅰ〜Ⅳ を選べる。
- LOADOUT：持っているスキルの装備とランクアップ。
- SHOP：XP でスキルを解放。
- SKIN：自機の色。
- LOG：航海日誌（全 24 ページ）とカットシーン（全 13 シーン）の再生。
- SECRETS：見つけた隠し要素の ON / OFF と称号（1 つ見つけると出現）。

## 物語の見せ方
- 3D カットシーン：Ⅰ 序章・終章 / Ⅱ 序章・告白・終章 / Ⅲ 序章・夢・終章 / Ⅳ 序章・盾・記録・終章 / ✈ 出発 の全 13 シーン。
- 無線：プレイ中、レイとパラス（ボス戦では敵も）の掛け合いが画面下に流れる。前回の死因・時間帯・章・進行状況で変わり、出撃をまたいで進む連作ネタもある。
- 航海日誌：記録・フェーズ到達・ボス撃破などで全 24 ページが解放される。
- リザルト：レイの一言（クールに決めようとして決まらない）。

## 縦画面
- ゲームは横画面専用。縦にすると「横向きにしてください」の画面になり、自己ベスト・パイロットレベル・ストーリーの進行（倒したボス）が出る。
- 背景では 3D のレイが羽ばたきながら飛び回り、パラスがあとを追い、ときどき自機が横切る。
- 第二部でミモザを救出すると、画面の下でひまわりの世話をする。第三部をクリアするとソルも加わり、ゆったり滑空しながら宙返りを見せる。キャラクターをタップすると反応する。

## 対応環境
- iOS Safari 15.4 以降 / Chrome / Edge / Firefox。
- 横画面専用。ノッチやホームインジケーター（セーフエリア）に対応。
- 60 / 120 / 144 Hz の端末で同じ難易度（経過時間ベースで計算）。
