# HOVER DODGE（ホバードッジ） スキル・やり込み・隠し要素

## XP の集め方
| ソース | XP |
|---|---|
| 生存（時間経過） | 1 秒あたり +2 |
| 敵の撃破（PULSE / 弾 / 連鎖） | +5 |
| 壁スレスレ通過（CLOSE）／極スレスレ（NEAR!） | +3 ／ +8 |
| XP オーブ（壁の隙間に出現。縁寄りは価値 2 倍） | +5 ／ +10 |
| PHASE 4 に初めて到達 | +60 |

## 仕組み
- SHOP でスキルを「解放」し、LOADOUT で「装備・ランクアップ」する。
- ランク：一部のスキルは Lv2〜3 に強化できる。
- パイロットレベル：累計の獲得 XP で上がる（最大 Lv80。XP を使っても下がらない）。
  - 称号：CADET → PILOT（10）→ ACE（20）→ VETERAN（30）→ COMMANDER（40）→ HERO（50）→ LEGEND（60）→ MYTHIC（70）→ ETERNAL（80）。
  - Lv3 / 7 / 12 / 20 / 45 / 60 で装備枠が 3〜8 枠に。
  - Lv5 / 14 / 25 / 38 / 52 / 66 で基本耐久 +1。
  - XP ボーナス（Lv30 まで 1 レベルごとに +1.5%、以降 +1%）。
  - Lv40 / 50 / 60 / 70 / 80 で限定スキン、Lv65 / 75 で新スキル（NIGHT EYE / ★MEMORY CORE）。
- HULL（耐久）：被弾はシールド → HULL の順に吸収。HULL が尽きると墜落。
- シナジー：特定の 2 スキルを同時に装備するとボーナス効果。
- 装備は単独で可能。ツリーの前提は「解放」にだけ必要。
- 全部解放して全ランクにすると合計 41,550 XP。

## スキルツリー
- ATTACK：FORWARD SHOT → TRIPLE SHOT → PIERCING ROUNDS → ★RAILGUN ／ MEGA PULSE → OVERLOAD ／ RAPID PULSE → AUTO-PULSE → ★STORM
- DEFENSE：SHIELD → DOUBLE SHIELD → REGEN SHIELD → ★AEGIS ／ PHOENIX → LAST STAND ／ TIME WARP → CHRONO BREAK
- PASSIVE：MAGNET → XP BOOST → GOLDEN ORBS ／ COMBO MULTIPLIER → OVERDRIVE ／ SMALLER HITBOX → GHOST DASH → ★PHASE SHIFT
- VITAL（パイロットレベルで解放）：HULL PLATING → REPAIR DRONE → NANO FRAME ／ IMPACT DAMPER → ADRENALINE → ★TITAN FRAME ／ REPAIR KIT → SECOND WIND
- Lv31 以降の上位スキル：OVERLOAD → TWIN PULSE ／ LAST STAND → IMMORTAL ／ GOLDEN ORBS → TREASURE HUNTER
- SOL（第三部クリアで解放）：SUNBURST → ACE INSTINCT ／ SOLAR FLARE → ★SUN BREAKER

## スキルの効果
### 攻撃（ATTACK）
- FORWARD SHOT（100 / 250 / 500）：タップで前方弾。クールダウン 0.40 → 0.32 → 0.25 秒。
- TRIPLE SHOT（400）：3 発に広がる。
- PIERCING ROUNDS（650）：弾が速くなり、2 体まで貫通。
- ★RAILGUN（1,500）：6 発ごとに画面端までの極太ビーム。
- MEGA PULSE（350 / 700）：PULSE の範囲 +30% / +60%。
- OVERLOAD（650）：PULSE で倒すごとにクールダウンが 1 秒回復。
- RAPID PULSE（250 / 600）：PULSE のクールダウン -30% / -45%。
- AUTO-PULSE（500）：クールダウンが明けると自動で発射。
- ★STORM（1,500）：撃破時に稲妻が近くの敵へ連鎖（最大 2 体）。
- TWIN PULSE（Lv33・1,800）：PULSE の直後にもう一度衝撃波。

### 防御（DEFENSE）
- SHIELD（150）：被弾を 1 回吸収し、周囲の敵を倒す。
- DOUBLE SHIELD（350）：シールド 2 枚。
- REGEN SHIELD（750）：シールド 1 枚。失うと 20 秒で再生。
- ★AEGIS（1,500）：シールド 1 枚。壊れたときに超巨大な衝撃波と時間停止。
- PHOENIX（500）：1 度だけ復活し、3 秒無敵。
- LAST STAND（800）：1 度だけ復活し、10 秒間スコアと XP が 2 倍。
- IMMORTAL（Lv40・2,200）：復活が 2 回に。復活のたびに LAST STAND。
- TIME WARP（450 / 900）：衝突の直前に自動でスローモーション。クールダウン 12 秒 → 8 秒。
- CHRONO BREAK（1,000）：TIME WARP（クールダウン 10 秒）＋発動中 0.5 秒無敵。

### 補助（PASSIVE）
- MAGNET（150 / 400）：NEAR の判定が広がり、XP オーブを吸い寄せる（範囲 90 → 140）。
- XP BOOST（350 / 700 / 1,200）：XP +25% / +40% / +60%。
- GOLDEN ORBS（700）：オーブの XP 2 倍、12% で金オーブ（+40）。
- TREASURE HUNTER（Lv44・1,800）：XP オーブの出現率アップ（45% → 75%）、金オーブの確率 2 倍。
- COMBO MULTIPLIER（400）：NEAR が続くと XP 倍率（最大 3 倍）。
- OVERDRIVE（800）：NEAR 5 連続でスコア 1.5 倍、NEAR ボーナス 2 倍。
- SMALLER HITBOX（400）：当たり判定 -33%。
- GHOST DASH（500）：羽ばたいた直後 0.15 秒無敵。
- ★PHASE SHIFT（1,500）：無敵 0.3 秒。無敵中に壁をすり抜けると PHASE ボーナス +40。

### 耐久（VITAL）
- HULL PLATING（Lv2・200）：最大耐久を増やす。
- REPAIR DRONE（Lv6・600）：一定時間ごとに耐久を 1 回復。
- NANO FRAME（Lv18・1,600）：耐久 +1。フェーズ到達とボス撃破のたびに耐久が全回復。
- IMPACT DAMPER（Lv9・700）：被弾後の無敵が 3.5 秒に。被弾の衝撃波で周りの敵を倒す。
- ADRENALINE（Lv15・900）：耐久が残り 1 の間、PULSE のチャージ 2 倍・XP 1.5 倍。
- REPAIR KIT（Lv11・500）：倒した敵がたまに修理キット（耐久 +1）を落とす。
- SECOND WIND（Lv37・1,400）：耐久が残り 1 になった瞬間、1 回だけ耐久 +1・2 秒無敵。
- ★TITAN FRAME（Lv55・3,000）：最大耐久 +2、被弾後の無敵 +1 秒。

### 高レベル・特別
- NIGHT EYE（Lv65・2,400）：最終章の夜で見える範囲 1.5 倍。スキルを忘れても半分の時間で思い出す。
- ★MEMORY CORE（Lv75・4,000）：1 ランに 1 度、撃墜される瞬間に 2 秒前の位置へ巻き戻る（周りの弾と壁が消え、2 秒無敵）。

### SOL 系統（第三部クリアで解放。ソルの機体のスキル）
- SUNBURST（1,200）：PULSE が太陽の光の輪に。範囲 +35%、眠りの霧を画面ごと晴らす。
- ACE INSTINCT（1,500）：NEAR の判定が広がり、NEAR 5 回ごとに耐久 +1。
- SOLAR FLARE（1,800）：前方の壁はすべて近づくだけで溶け、隙間 +40%。PULSE で画面の壁を一気に最大 +70% まで溶かす。
- ★SUN BREAKER（3,000）：PULSE のたびに 2.5 秒の SUN DIVE。機体が太陽になり、ぶつかった壁を何枚でも粉砕して突き抜ける（1 枚 +5 XP）。

## シナジー（2 つ同時に装備したときのボーナス）
| シナジー | 組み合わせ | 効果 |
|---|---|---|
| BARRIER PULSE | RAPID PULSE ＋ SHIELD | PULSE 発動時に 0.5 秒無敵 |
| SCAVENGER | TRIPLE SHOT ＋ MAGNET | 弾で倒した敵が XP オーブを落とす |
| SLIPSTREAM | COMBO MULTIPLIER ＋ GHOST DASH | NEAR のたびに PULSE のクールダウンが 1 秒回復 |
| SALVAGE | PHOENIX ＋ XP BOOST | 復活時に +100 XP |
| FORTRESS | AUTO-PULSE ＋ DOUBLE SHIELD | シールドが壊れると PULSE が即チャージ |
| BULLET TIME | TIME WARP ＋ FORWARD SHOT | スローモーション中は射撃のクールダウンなし |
| BULWARK | HULL PLATING ＋ SHIELD | 耐久が減ると PULSE が即チャージ |

## スキン（自機の色）
- 最初から：CYAN（初期）、MAGENTA、EMERALD、FIRE、VOID、GOLD。
- パイロットレベル：NEBULA（Lv40）、AEGIS（Lv50）、LEGEND（Lv60・アニメーション）、NIGHT（Lv70・星がまたたく）、DAWN（Lv80・朝焼けから金色へ）。
- ストーリー：SOL（第三部クリア。ソルの機体）。
- 隠し要素：GLITCH、PACIFIST、PRISM（全部発見）。
- 横画面では格納庫風のライブ 3D プレビュー（実機モデルが回転）、縦画面ではシルエットでプレビュー。
