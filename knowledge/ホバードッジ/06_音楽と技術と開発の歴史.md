# HOVER DODGE（ホバードッジ） 音楽・技術・開発の歴史

## インタラクティブミュージック
- 外部の音源ファイルを使わず、WebAudio ですべて手続き合成している。BGM は固定ループではなく、プレイ内容にリアルタイムで反応する。
- 横の再構成：タイトルと各フェーズに専用のセクションがあり、テンポ・コード進行・グルーヴが変わる。切り替えは必ず次の小節の頭で、着地点にクラッシュとサブドロップ。フェーズ到達を予測して、1 小節前からライザーとスネアロールを走らせる。

- 縦のレイヤリング：危険度（前方の壁や敵との近さ）でテンションのレイヤーやハイハット、ベースのフィルターが開く。ヒート（NEAR や撃破の連続）でアルペジオが入り、最高潮ではリードが 1 オクターブ上へ。
- 拍に同期する音：NEAR は次の 16 分に合わせたベル音（いまのコードの構成音で、コンボが続くほど音程が上がる）。撃破はコードスタブ。10 秒ごとにシンバル。
- 状態とミックス：一時停止で音がこもる（ローパス）。スローモーションでフィルターが沈む。死亡時は「電源断」のように 1.3 秒でフェードアウト。新記録で A メジャーのファンファーレ。PULSE やシールドで音楽が一瞬ダッキング。
- しゃべる声：セリフの文字送りに合わせて、話者ごとに違う短い音が鳴る（レイはさえずり、パラスは電子音、ハデスは低いうなり など）。

## 技術スタック
- Three.js（r160、CDN）：シーン、ライティング、ポストプロセス（UnrealBloomPass と自作のレンズシェーダー）、GLTFLoader。
- 素の JavaScript（ES Modules）：ゲームロジック、入力、状態管理。モデルが読めないときはコードで生成したモデルで動く。
- カットシーン：汎用エンジン「Cine」（台詞・タイプライター・SKIP・ベール遷移・カメラ補間）。回想はセピア、ソルのホログラムはシェーダー（縁の発光と走査線）。
- 縦画面の 3D は別の小さな WebGL レンダラー（縦画面のときだけ動き、裏の描画を止める）。
- HUD と各画面は DOM と CSS。スコアのポップアップは Canvas 2D。
- Web Audio API：効果音・声・BGM をすべて手続き合成。
- Service Worker：オフライン対応の PWA。ページ本体はネット優先、3D モデルは専用キャッシュ。新しいバージョンが出るとタイトルに「NEW VERSION — タップで更新」。
- アクセス解析は GoatCounter（Cookie なし、個人を特定する情報なし）。出撃・ボス撃破・章クリア・撃墜の場所を記録。
- 保存は端末の localStorage（自己ベスト、XP、スキル、スキン、音の設定、ボス撃破数、章の進行、会話履歴、隠し要素など）。
- ゲーム本体は index.html の 1 ファイル（CSS と JS 全部入り）。依存は CDN の Three.js と Google Fonts（Orbitron / Rajdhani）だけ。
- 3D モデル（glTF）：自機、レイ、パラス、各ボスの旗艦、ミモザ、ソル、ハデス、ニュクス、レテ、パウロなど。
- 見た目の特徴：800×450 の仮想画面を解像度に合わせて描画、色収差・ビネット・走査線・フィルムグレイン、ネオンの発光、シンセウェイヴ風の奥行きグリッド、エンジンの航跡。
