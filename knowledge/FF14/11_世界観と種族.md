# FF14 世界観・種族・国（ネタバレなし）

## 星と大陸
- 舞台の星は「ハイデリン」（「アーテリス」とも呼ばれる）。冒険の中心は、三大陸のひとつにある地域「エオルゼア」。
- エオルゼアの主な地域：ラノシア（海と島）、黒衣森（森）、ザナラーン（砂漠）、クルザス（雪原）、モードゥナ（クリスタルの地）、ギラバニア（山岳）。
- 東方には「ひんがしの国」や「ドマ」、北州イルサバードには「ガレマール帝国」、学術都市「シャーレアン」、新大陸「トラル大陸」などがある。
- 時間は「エオルゼア時間」で流れていて、現実の約70分でゲーム内の1日になる。天候も地域ごとに変わる。

## 国と都市
| 都市 | 地域 | 性格 |
|---|---|---|
| リムサ・ロミンサ | ラノシア | 海の都。元は海賊の国。提督が率いる |
| グリダニア | 黒衣森 | 森の都。精霊と共に生きる |
| ウルダハ | ザナラーン | 砂の都。商人と王家の国。富と格差 |
| イシュガルド | クルザス | 宗教国家。長く竜と戦争していた |
| アラミゴ | ギラバニア | 帝国から独立を取り戻した山の国 |
| ドマ | オサード小大陸 | 東方の国。忍びと侍の文化 |
| シャーレアン | 北洋 | 学問の都。知識を重んじる |
| トライヨラ | トラル大陸 | 黄金郷とも呼ばれる多民族国家 |
- グランドカンパニー（軍事組織）：黒渦団（リムサ）、双蛇党（グリダニア）、不滅隊（ウルダハ）。冒険者はどれか1つに入る。

## 種族（プレイヤーが選べる）
| 種族 | 特徴 |
|---|---|
| ヒューラン | 人間に近い。最も数が多い |
| エレゼン | 背が高く耳が長い。イシュガルドの貴族に多い |
| ララフェル | 小柄。商売や学問に優れる |
| ミコッテ | 猫の耳と尻尾 |
| ルガディン | 大柄で力強い。海の民と山の民 |
| アウラ | 角と鱗を持つ東方の種族 |
| ロスガル | 獅子のような獣人 |
| ヴィエラ | うさぎのような長い耳。森に住む |
- ロスガルとヴィエラは、もともと片方の性別だけだったが、のちに両方の性別が選べるようになった。

## 世界の大きな仕組み（ネタバレの少ない範囲）
- エーテル：万物に宿る力。魔法はエーテルを操る技術。
- 蛮神：強い祈りによって呼び出される神。呼び出した者を「テンパード」（信者）として支配し、土地のエーテルを吸い上げる。
- 光の戦士：「超える力」を持つ冒険者。蛮神のテンパード化を受けず、他人の過去を見ることがある。
- 暁の血盟：世界の危機に立ち向かう組織。主人公（冒険者）が参加する。
- 霊災：世界を襲う大災害。新生エオルゼアの物語は「第七霊災」のあとから始まる。
- クリスタル：エーテルの結晶。テレポの拠点（エーテライト）や生活の道具に使われる。

## 主な仲間（序盤から出てくる人々）
- ミンフィリア：暁の血盟の盟主。
- アルフィノとアリゼー：シャーレアンから来た双子。兄は理想家、妹はまっすぐな行動派。
- ヤ・シュトラ：ミコッテの魔法使い。冷静な知恵袋。
- サンクレッド：腕の立つ大人の剣士。情報収集が得意。
- ウリエンジェ：言い回しが難しい賢人。
- タタル：暁の受付と財政担当のララフェル。
- ムーンブリダ、ラハ（グ・ラハ・ティア）、エスティニアン、ウクラマト など、物語を進めるほど仲間が増える。
