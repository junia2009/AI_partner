# FF14 金策とマーケット

## ギル（お金）の基本
- 主な使い道：テレポ、装備の修理、マテリア、ハウジング（家と家具）、見た目装備、ミニオンやマウントの購入。
- 戦闘の報酬だけでも生活はできる。大きなお金が必要なのは、主にハウジングと見た目集め。

## マーケットボード
- 都市やハウジングエリアにある、プレイヤー同士の売り買いの掲示板。
- 自分の物を売るには「リテイナー」（雇い人）に預けて出品する。
- 売れると販売手数料が差し引かれる（出品する都市によって割合が少し違う）。
- 同じデータセンター（DC）の中なら、ほかのワールドの出品も見て買える（ワールド間の価格差を使う人もいる）。
- 相場の確認：同じアイテムの直近の売買履歴を見て、安すぎ・高すぎを避ける。

## リテイナー
- 雇うと、所持品を預けたり、マーケットに出品したり、「リテイナーベンチャー」（探索・調達）に行かせたりできる。
- 標準で2人まで。追加は有料オプション。
- リテイナーベンチャーで、素材や見た目装備、レアなアイテムを持ち帰ることがある。

## 金策の定番
| 方法 | 内容 | 向いている人 |
|---|---|---|
| ギャザラーの素材を売る | 新パッチ直後の新素材は特に高い | ギャザラーを上げた人 |
| クラフター製品を売る | 新しい装備・食事・薬・家具 | クラフターを上げた人 |
| 宝の地図 | パーティで地図を掘り、宝箱とダンジョン（宝物庫）で稼ぐ | みんなで遊びたい人 |
| 零式・極の素材 | 報酬アイテムを売る | 戦闘が好きな人 |
| 討滅戦のマウントやミニオン | 取引できるものは高値になることがある | 消化に通う人 |
| リテイナーベンチャー | 放っておいても少しずつ稼げる | 忙しい人 |
| ディープダンジョンの宝箱 | 見た目装備などが出る | 周回が好きな人 |
| ルーレットと日課 | ギルと交換アイテムが手に入る | だれでも |

## 金策のコツ
- 新パッチ直後は、レシピ素材・新しい食事・薬・新装備の需要が一気に上がる。早く作れるほど高く売れる。
- 「みんなが毎日使う物」（料理・薬・マテリア）は値崩れしにくい。
- ハウジング家具や染料は、イベントや季節で値段が動く。
- 出品はこまめに見直す。極端に安い出品と競争しすぎない。
- ギャザラー・クラフターを全部上げると、仕入れから販売まで自分でできる。

## してはいけないこと
- 外部のサイトでギルを買う「RMT」は規約違反（アカウント停止の対象）。お金がらみの怪しい誘いには乗らない。
