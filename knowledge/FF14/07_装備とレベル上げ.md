# FF14 装備・アイテムレベル・レベル上げ

## アイテムレベル（IL）
- 装備の強さを表す数字。コンテンツには「平均 IL いくつ以上」の参加条件がある。
- 主な装備の入手先（レベル上限のとき）：
  - ダンジョン・ルーレット：最初の装備。
  - トークン（トームストーン）：毎週の上限まで集めて交換。パッチごとに新しい種類になり、前の種類は交換レートが下がる。
  - クラフター製の装備：マーケットで買える。HQ（高品質）のほうが強い。
  - ノーマルレイドのトークン：交換で装備。
  - 零式：最新の最強装備。週1回の報酬制限。強化素材で「トームストーン装備」を強化できる。
- 武器のIL は特に重要（ダメージへの影響が大きい）。

## サブステータス（ざっくり）
| ステータス | 効果 |
|---|---|
| クリティカル | 会心の確率と倍率が上がる |
| ダイレクトヒット | 直撃（ダメージ1.25倍）の確率が上がる |
| 意思力 | 与ダメージ・回復量が少し上がる |
| スキルスピード／スペルスピード | GCD が短くなる |
| 不屈（タンク） | 被ダメージ減・与ダメージ増 |
| 信仰（ヒーラー） | MP の回復が増える |
- 一般には「クリティカル優先」が多い。スピードはジョブや好みで調整（GCD の長さに合わせて組む）。

## マテリア
- 装備の穴（マテリア穴）にはめて、ステータスを足す石。
- 穴の数を超えてはめる「禁断」は、失敗することがある（数を重ねるほど成功率が下がる）。
- 「マテリア精製」：装備を長く使って「錬精度」が100%になると、マテリアを取り出せる。
- 上限：装備ごとに各ステータスの上がり幅に上限がある。超えた分はムダになる。

## 見た目（ミラージュプリズム）
- 装備の見た目を、別の装備に変えられる。
- 「ミラージュドレッサー」に見た目を保存して、いつでも使える。
- 「グラマープレート」で見た目のセットをまとめて切り替えられる。
- カララント（染料）で染められる装備も多い。

## レベル上げの方法
| 方法 | 特徴 |
|---|---|
| メインクエスト | 経験値がとても多い。最初のジョブはこれで十分 |
| ルーレット（レベリング） | 1日1回の大きなボーナス。ほかのルーレットもボーナスあり |
| ダンジョン周回 | 自分のレベルに合ったダンジョンを繰り返す。最も一般的 |
| ディープダンジョン | 死者の宮殿（〜60）、アメノミハシラ（〜70）、オルト・エウレカ（〜90）。決まった階層を周回 |
| FATE | フィールドの突発イベント。拡張の地域の FATE は報酬（ジェム）と経験値が多い |
| 友好部族クエスト | 各地域の部族の日課クエスト。経験値が多く、ミニオンやマウントも |
| ジョブクエスト | 新しい技がもらえる。必ずこなす |
| 冒険者小隊、フェイス | NPC と気楽にダンジョンへ |

## 経験値ボーナス
- 休息ボーナス：街や宿屋でログアウトしている間にたまる。経験値が増える。
- アーマリーボーナス：いちばん高いレベルのジョブより低いジョブを育てるとき、経験値アップ。
- 経験値アップの食事、FC（フリーカンパニー）のアクション、「経験値アップの指輪」（レベル30までなど）。
- 新しい拡張のジョブ（例：ヴァイパー、ピクトマンサー）は、高いレベルから始まる。

## 装備をそろえる流れ（新パッチの例）
1. 新しいトームストーンを毎週上限まで集める（ルーレット・討滅戦・アライアンス）。
2. マーケットのクラフター装備で穴埋め。
3. 零式の1〜2層で装備や強化素材を取る。
4. 武器はトームストーン武器（強化）か零式の最終層。
5. マテリアで仕上げる。
