# FF14 コンテンツの種類と攻略の進め方

## 戦闘コンテンツの種類
| 種類 | 人数 | 内容 |
|---|---|---|
| ダンジョン（インスタンスダンジョン） | 4人 | 雑魚をまとめて倒しながら進み、ボス3体ほどを倒す。レベル上げの主役 |
| 討伐・討滅戦 | 8人 | ボス1体との戦い。ノーマル・真（ハード）・極（エクストリーム）の難易度 |
| ノーマルレイド | 8人 | 拡張ごとのレイドシリーズ。物語が楽しめる |
| 零式（セイヴァー） | 8人 | ノーマルレイドの高難易度版。最新装備が手に入る |
| 絶（アルティメット） | 8人 | 最高難易度。長い戦闘を完璧に処理する必要がある |
| アライアンスレイド | 24人 | 3パーティで挑む大型レイド。物語も豪華 |
| ディープダンジョン | 1〜4人 | ランダムな階層を下っていく探索型。レベル上げにも使える |
| 特殊フィールド | 多人数 | 専用のレベルや装備で広いフィールドを探索（エウレカ、ボズヤ など） |
| ヴァリアント／アナザーダンジョン | 1〜4人 | 分岐や高難度版のあるダンジョン（暁月のころの遊び） |
| PvP | さまざま | クリスタルコンフリクト（5対5）、フロントライン（多人数）など |
| ギャザラー・クラフターのコンテンツ | 1人〜 | 収集品、蒼天街の復興、宇宙開拓系の協力コンテンツなど |

## 難易度ごとの目安
- ノーマル：メインクエストの流れで挑む。初見でも攻略可能。
- 極：ノーマル版の高難易度。予習推奨。マウント（武器や騎乗動物）が報酬。
- 零式：パッチ初期は世界中で攻略を競う。週に1回の報酬制限があり、毎週少しずつ装備を集める。
- 絶：過去の名場面を再構成した長い戦い。予習と練習に数十時間〜数百時間かかることも。報酬は武器と称号など（装備としての強さより名誉）。

## ディープダンジョン
- 死者の宮殿（新生、レベル1〜60）、アメノミハシラ（紅蓮、61〜70）、オルト・エウレカ（暁月、81〜90）、黄金のレガシーでも新しいものが追加されている。
- 入るとレベルと装備がリセットされ、ダンジョン専用の強化（武器・防具の強化値）を育てる。
- 「ポマンダー」（魔器）で罠を見破ったり、敵を変身させたりできる。
- 低い階層はレベル上げに便利。深い階層をソロで攻略するのは非常に難しい（ソロ踏破は名誉）。

## 攻略の進め方（ノーマル→零式）
1. 最新のメインクエストを終わらせる。
2. 「トームストーン」（パッチごとに名前が変わる通貨）を毎週集めて、IL の高い装備と交換する。
3. 極の討滅戦や、ノーマルレイドでの装備で IL を上げる。
4. 零式は1層から順に。予習 → 練習募集 → クリア の繰り返し。1週間に取れる報酬に上限がある。
5. 装備がそろったら、マテリア（ステータスを上げる石）をはめて仕上げる。

## よく使うルーレット
- レベリング：低〜中レベルのダンジョン。1日1回ボーナスが大きい。
- ハイレベリング：レベル上限のひとつ前までの高レベルダンジョン。
- メインクエスト：メインストーリーの長いコンテンツ（新生のラストを飾る「カストルム・メリディアヌム」「魔導城プラエトリウム」など）。時間がかかるが報酬が多い。
- 討伐・討滅戦、アライアンスレイド、ノーマルレイド、エキスパート（最新のダンジョン）。
- 「レベル50/60/70/80/90」：各拡張の上限レベルのダンジョン。
- 新人がパーティにいるとボーナスが増える（メンターの見守りにもなる）。

## PvP
- クリスタルコンフリクト：5対5。中央のクリスタルを運ぶ。ランクマッチあり。
- フロントライン：3陣営による多人数戦。拠点を取り合う。
- ライバルウィングズ：ロボットに乗る大規模戦。
- PvP は専用の技と簡略化された回し方になる。報酬は見た目装備やマウント。
