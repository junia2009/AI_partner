# エスプレッソとバリスタの技術

## エスプレッソとは
- 細かく挽いた粉を固く詰め、90〜96℃のお湯を約9気圧の圧力で短時間（25〜30秒ほど）通して淹れる、濃縮されたコーヒー。
- 1900年代初めのイタリアで生まれた。「エスプレッソ」はイタリア語で「急行」「すぐに用意された」などの意味。
- 表面の黄金色の泡「**クレマ**」は、豆の炭酸ガスと油分が圧力で乳化したもの。焙煎から日が浅いほど多く、ロブスタを混ぜると厚くなる。クレマが多い＝おいしい、とは限らない。
- 味の構成：酸味・甘み・苦みが凝縮され、とろりとした重いボディ。カフェラテなどミルクドリンクの土台になる。

## 基本のレシピ（ダブルショット）
- **粉の量（ドーズ）**：18g前後（バスケットの大きさに合わせて16〜22g）。
- **抽出量（イールド）**：36g前後（粉の約2倍＝ブリューレシオ 1:2）。
- **抽出時間**：25〜30秒（お湯が粉に触れ始めてから）。
- **湯温**：90〜96℃（93℃前後が基準。浅煎りは高め、深煎りは低め）。
- **圧力**：約9気圧。
- 抽出量は「量（ml）」ではなく「重さ（g）」で測るのが今の主流。クレマで量が変わって見えるため。

### ショットの種類
- **リストレット**：1:1〜1:1.5。短く絞る。甘みと濃さが強く、苦みが少なめ。
- **ノルマーレ（通常）**：1:2前後。
- **ルンゴ**：1:3以上。長く出す。軽いが苦み・渋みも出やすい。
- **シングル**：粉7〜10gで1杯分（約30ml）。**ダブル（ドッピオ）**：粉14〜20gで2杯分または濃い1杯。
- 浅煎りの豆では、1:2.5〜1:3の長めの比率で、甘さと透明感を引き出すレシピも多い。

## ダイヤルイン（味の調整）
- その日の豆・気温・湿度に合わせて、レシピを合わせることを「ダイヤルイン」と呼ぶ。開店前のバリスタの日課。
- 基本は **粉の量を固定** → **抽出量を決める** → **挽き目で時間を合わせる** → **味を見る** の順。
- **酸っぱい・薄い・早く落ちる（20秒未満）**：未抽出。挽き目を細かくする、抽出量を増やす、湯温を上げる。
- **苦い・渋い・遅い（35秒以上）**：過抽出。挽き目を粗くする、抽出量を減らす、湯温を下げる。
- **酸っぱくて苦い、時間がおかしい**：チャネリング（後述）を疑う。粉のならしと詰め方を見直す。
- 一度に変えるのは1つだけ。グラインダーの挽き目を変えたら、中に残った前の粉を少し捨てて（パージ）から試す。

## パック（粉の層）の作り方
1. **ポルタフィルター**（取っ手のついた粉の受け皿）を乾いた布で拭き、温めておく。
2. **計量**：0.1g単位のスケールで粉の量を毎回そろえる。
3. **分散（ディストリビューション）**：粉の偏りやダマをなくす。細い針で粉をかき混ぜる「**WDT（ワイス・ディストリビューション・テクニック）**」が効果的。ディストリビューションツール（レベラー）で平らにならす方法も。
4. **タンピング**：タンパーで粉を水平に、しっかり押し固める。強さは15〜20kg程度が目安と言われるが、大切なのは**毎回同じ力で、水平に**押すこと。押したあと、ひねってこすったり、叩いたりはしない。
5. 縁に付いた粉を払い、すぐにマシンにセットして抽出する（グループヘッドの熱で粉が焼けないように）。

## チャネリング
- お湯が粉の層の弱い部分に集中して流れ、「水の道（チャネル）」ができてしまうこと。
- 一部は過抽出、一部は未抽出になり、酸っぱさと苦さが同時に出る。
- 原因：粉の偏り、ダマ、斜めのタンピング、粉の量が合っていない、ポルタフィルターをぶつけた、など。
- **ボトムレス（ネイキッド）ポルタフィルター**を使うと、底から抽出の様子が見え、チャネリングが一目でわかる（細い噴き出し＝チャネリング）。

## 器具とマシン
- **エスプレッソマシン**：ボイラーの種類（シングル、熱交換式、デュアルボイラー）、温度制御（PID）、プレインフュージョン（最初に低い圧力で粉を湿らせる）機能などがある。
- **グラインダー**：エスプレッソは挽き目のわずかな差で味が大きく変わるため、マシンと同じくらい重要。細かい調整ができる臼式（バー）を選ぶ。
- **バスケット**：粉の量に合ったものを使う。穴の精度が高い「精密バスケット」もある。
- **ミルクピッチャー**：ステンレス製。350ml（ラテ1杯）、600mlなど。注ぎ口の形でラテアートの描きやすさが変わる。
- **ノックボックス**：使い終わった粉（パック）を捨てる箱。

## ミルクのスチーミング
- スチームワンド（マシンの蒸気ノズル）で、ミルクを温めながら空気を含ませ、きめ細かな泡（**マイクロフォーム**）を作る。
- 目標は、ツヤがあって、ペンキのようにとろりとした泡。大きな泡（ブクブク）がない状態。

### 手順
1. ピッチャーとミルクは**よく冷やしておく**（作業時間が長くとれる）。ラテ1杯なら350mlピッチャーに半分弱ほど注ぐ。
2. スチームワンドから空吹き（パージ）して、中の水滴を出す。
3. ノズルの先をミルクの表面のすぐ下に入れ、蒸気を全開にする。
4. **空気を入れる（ストレッチング）**：ノズルを表面ぎりぎりにして「チリチリ」「チッチッ」という小さな音を立て、空気を含ませる。ミルクの量が増えていく。手で触ってぬるい（35〜40℃）くらいまでに終える。
   - カフェラテ：量が1〜2割増える程度（泡は薄め）。
   - カプチーノ：量が3〜5割増える程度（泡は厚め）。
5. **混ぜる（テクスチャリング・ローリング）**：ノズルを少し沈め、ピッチャーの中でミルクが渦を巻くようにして、大きな泡を細かく砕きながら温める。
6. **55〜65℃**（ピッチャーを持つ手が熱くて持っていられなくなる少し手前）で止める。60〜65℃ごろが甘みを最も感じやすい。70℃を超えると甘みが落ち、焦げたような匂いが出る。
7. ノズルをすぐ濡れ布巾で拭き、空吹きする（ミルクが固まって詰まるのを防ぐ）。
8. ピッチャーを台に軽く打ちつけて大きな泡を消し、回して表面にツヤを出す。すぐに注ぐ。

### ミルクの選び方
- **牛乳**：たんぱく質が泡の骨格を作り、脂肪がコクとなめらかさを作る。成分無調整の牛乳（乳脂肪3.5％前後）が泡立ち・味ともに扱いやすい。低温殺菌牛乳は甘みが自然。
- **低脂肪乳**：泡は立ちやすいが、軽くて粗くなりやすい。
- **植物性ミルク**：オーツミルクが人気。泡立ちやすく作られた「バリスタ用」を選ぶと、ラテアートもしやすい。ソイ（豆乳）はコーヒーの酸で分離しやすいので、温度を上げすぎない。アーモンドミルクは泡が軽め。

## ラテアート
- エスプレッソの上にスチームミルクを注いで模様を描く技術。注ぐだけで描く「**フリーポア**」と、ピックなどで描く「**エッチング**」がある。

### 基本の流れ
1. カップを少し傾けて持ち、エスプレッソの中心に、**高い位置から細く**ミルクを注ぐ。泡を沈めながら、エスプレッソとミルクを混ぜて土台（キャンバス）を作る。
2. カップが半分〜6割ほど満たされたら、ピッチャーの注ぎ口を**表面ぎりぎりまで近づけ**、注ぐ量を少し増やす。白い泡が表面に浮かび始める。
3. 模様を描く（下記）。
4. 最後にピッチャーを**少し持ち上げて細く**し、模様を貫くように手前から奥へ「切る」と形が締まる。

### 代表的な模様
- **ハート**：一か所に注ぎ続けて白い円を大きくし、最後に持ち上げて真ん中を切る。最初に練習する模様。
- **リーフ（ロゼッタ）**：ピッチャーを左右に小刻みに振りながら（ウィグル）、手前へ下がっていき、最後に奥へ切る。葉っぱの模様。
- **チューリップ**：小さな白い円を、少しずつ押し込みながら重ねていき、最後に切る。重ねる数で難しさが変わる。
- **スワン**などの応用：リーフとハートを組み合わせる。

### 上達のコツ
- 失敗の多くは**ミルクの状態**が原因。泡が多すぎると模様が浮かばず、少なすぎると白く出ない。
- エスプレッソのクレマが新しいうちに注ぐ。
- 練習には、水に少量の洗剤を入れて泡立てたもので注ぎの動きだけ練習する方法もある。
- 毎回スマートフォンで写真を撮り、比べると上達が早い。

## 掃除とメンテナンス
- **毎回**：抽出後にポルタフィルターの粉を捨て、グループヘッドに空吹きしてお湯を流す。スチームワンドは使うたびに拭いて空吹き。
- **毎日（営業終わり）**：ブラインドバスケット（穴のないバスケット）と専用洗剤で「**バックフラッシュ**」をし、グループヘッドの中の油汚れを流す。シャワースクリーンとガスケット周りをブラシで掃除。ポルタフィルターとバスケットを洗剤につけ置き。
- **定期的に**：グラインダーの刃の掃除（専用のクリーニング粒を使う方法も）、ガスケット（ゴムパッキン）の交換、浄水器のフィルター交換。
- **スケール（水垢）対策**：硬度の高い水はボイラーに水垢がたまり、故障の原因になる。浄水器・軟水器を使い、メーカーの指示に従って除去する。
- 古いコーヒーオイルは酸化して、嫌な苦み・渋みのもとになる。「掃除がおいしさを作る」がバリスタの合言葉。

## バリスタの仕事と心がまえ
- **バリスタ**はイタリア語で「バールでコーヒーを淹れる人」。エスプレッソを中心に、ドリップ、ミルクドリンク、接客まで担う。
- **開店準備**：マシンの温度を安定させる、ダイヤルイン、ミルクやカップの補充、作業場の整頓（ミザンプラス）。
- **作業の流れ（ワークフロー）**：注文を受ける → 粉を挽く → パックを作る → 抽出を始める → その間にミルクを温める → 注ぐ → 提供。複数のドリンクを同時に効率よく作る段取りが大切。
- **一貫性**：同じお客さんに毎回同じ味を出すこと。計量と記録が支えになる。
- **ホスピタリティ**：お客さんの好みを聞き、豆やドリンクを提案する。コーヒーの物語（産地・農園・精製）を伝えるのも仕事。
- **衛生**：ミルクは温度管理を徹底し、作業台・布巾を清潔に保つ。

## 資格と競技会
- **SCA コーヒー・スキル・プログラム**：スペシャルティコーヒー協会の認定講座。バリスタ、ブリューイング、センサリー（官能評価）、ロースティング、グリーンコーヒーの各分野に、初級・中級・上級がある。
- **Qグレーダー**：CQI（コーヒー品質協会）が認定する、コーヒーの品質を評価する専門家の資格。カッピングや香りの判別などの試験がある。
- **JBA（日本バリスタ協会）のバリスタライセンス**、**SCAJ（日本スペシャルティコーヒー協会）のコーヒーマイスター**など、日本独自の資格もある。
- **ワールド・バリスタ・チャンピオンシップ（WBC）**：世界のバリスタの頂点を決める大会。各国の予選（日本では JBC：ジャパン・バリスタ・チャンピオンシップ）を勝ち抜いた代表が、15分間のプレゼンテーションで、エスプレッソ、ミルクドリンク、オリジナルの「シグネチャービバレッジ」を審査員に提供し、味・技術・プレゼンで競う。
  - 2014年に日本の**井崎英典**さんがアジア人として初めて優勝。
  - 2025年はオーストラリアの**ジャック・シンプソン**さんが優勝（オーストラリア4人目の王者）。
- ほかに、ハンドドリップなどを競う「ワールド・ブリュワーズ・カップ（WBrC）」（2016年に日本の粕谷哲さんが優勝）、ラテアートの「ワールド・ラテアート・チャンピオンシップ」、焙煎の「ワールド・コーヒー・ロースティング・チャンピオンシップ」、カップテイスターズ（味の聞き分け）などの世界大会がある。
