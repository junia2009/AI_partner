# Microsoft 連携（OneDrive・Excel）の準備

パラスが、個人の Microsoft アカウントの OneDrive にある Excel を読み書きできるようにするための手順です。
最初に一度だけ、Microsoft 側に「パラス」というアプリを登録します（5 分ほど）。

## 1. アプリを登録する

1. <https://entra.microsoft.com> を開き、個人の Microsoft アカウント（Outlook.com など）でサインインします。
   - 開けないときは <https://portal.azure.com> から「Microsoft Entra ID」→「アプリの登録」へ進みます。
   - Azure のアカウント（無料）の作成を求められることがあります。本人確認でクレジットカードの登録を求められる場合がありますが、アプリの登録だけなら料金はかかりません。
2. 「アプリの登録」→「新規登録」を押します。
3. 次のように入力して「登録」を押します。
   - **名前**：パラス（なんでもよい）
   - **サポートされているアカウントの種類**：**個人用 Microsoft アカウントのみ**
   - **リダイレクト URI**：プラットフォームは **シングルページ アプリケーション (SPA)**、URI は
     `https://junia2009.github.io/AI_partner/`
4. 登録後の「概要」にある **アプリケーション (クライアント) ID** をコピーします（`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` の形）。
   - これは秘密の値ではありません（ブラウザだけのアプリでは公開してよい ID です）。

アクセス許可（API のアクセス許可）は追加しなくても大丈夫です。初めてサインインするときに、パラスが必要な許可（ファイルの読み書き）を求め、その画面で「はい」を押せば使えるようになります。

## 2. パラスにつなぐ

1. パラスの「設定」→「連携」→「Microsoft」に、コピーした ID を貼り付けます。
2. 「Microsoftに接続」を押すと、Microsoft のサインイン画面に移ります。サインインして、アクセスの許可を求められたら「はい」を押します。
3. パラスの画面に戻り、「Microsoft に接続しました」と出れば完了です。

## 3. できること

- 「家計簿の Excel を見せて」：ファイルを探して中身を読み、画面に表のカードを出します。
- 「家計簿に今日のランチ 800 円を足して」：表の一番下に行を足します。
- 「B10 に合計を入れて」：`=SUM(B2:B9)` のような数式で入れ、計算は Excel に任せます。
- 「読書記録の表を作って。見出しは日付・タイトル・感想」：OneDrive に新しい Excel ファイルを作ります。
- すでに値が入っているセルを書き換えるときは、パラスが元の値を伝えて確認してから書き換えます。
- 間違えて書き換えてしまっても、OneDrive の「バージョン履歴」から前の状態に戻せます。

## 注意

- パラスが読んだ Excel の中身は、返事を考えるために Claude（Anthropic）に送られます。見られて困る情報が入ったファイルは、パラスに扱わせないでください。
- サインインの情報はこの端末のブラウザにだけ保存されます。「接続を解除」を押すと、この端末から消えます。
- しばらく使わないとログインが切れることがあります。そのときは設定からもう一度「Microsoftに接続」を押してください。
