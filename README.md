# AIパラス（AI_partner）

マスター専属の音声AIアシスタント「パラス」です。話しかけると声で答え、予定・メール・地図・タイマー・やること・専門知識の調べものまで手伝います。
ブラウザで動く1枚のページ（`index.html`）で、GitHub Pages で公開しています。

**▶ 公開ページ：https://junia2009.github.io/AI_partner/**

iPhone・iPad は Safari／Edge の「ホーム画面に追加」でアプリのように使えます（PWA）。

---

## パラスについて
- 冷静で有能、プライドを持った相棒。忠実だけど言いなりではなく、意見を言いつつ最終判断はマスターに任せます。先回りして気を配ります。
- 呼び方の基本は「マスター」。名前を教えると、その呼び名（ひらがなで登録）で呼びます。
- 人格の設定は [`persona.md`](persona.md) にまとめています（`index.html` の中の指示と同じ内容）。

## できること

| 機能 | 話しかけ方の例 |
|---|---|
| 💬 音声会話 | マイクボタンかパラス本体をタップして話す。連続会話もできる |
| 🧠 記憶 | 「コーヒーは浅煎りが好きなんだ、覚えといて」「〇〇のこと忘れて」 |
| ⏰ タイマー・アラーム | 「10分後に教えて」「7時に起こして」 |
| 📝 やること | 「牛乳買うの追加して」「やること読んで」「牛乳買った」 |
| ☀ 朝の報告 | 朝はじめて開いたとき、今日の予定・やること・タイマーをまとめて伝える |
| 📅 Google カレンダー | 「明日の予定は？」「金曜15時に打ち合わせ入れて」 |
| ✉️ Gmail | 「未読メールまとめて」「それに返信の下書きして」（送信はせず下書きに保存） |
| 🗺 お店・場所の検索 | 「近くのカフェある？」「今開いてるラーメン屋」→ 地図つきカード |
| 🧭 経路案内（ナビ） | 「東京駅までの行き方」「渋谷まで何分？」→ 経路カードと「ナビ開始」ボタン |
| 📚 知識（RAG） | `knowledge/` に置いた資料を調べて答える（例：コーヒーの資料） |
| 🗑 ごみ出し（東久留米） | 「明日何ごみ？」「電池って何ごみ？」→ 東久留米ごみナビ（higashikurume_gomi）のデータで答える |
| 🏠 おうちの環境 | 「部屋、乾燥してる？」「今週の室温は？」「今日の電気代は？」→ SwitchBot の記録（smart_home_db）からグラフつきで答える |
| 🎵 BGM | 「BGM流して」「落ち着く曲にして」「止めて」と話しかける。景色に合わせた曲をその場で合成して流す |
| 🌌 景色 | 背景が時間帯や気まぐれで変わる。「宇宙に行こう」「雨の景色がいい」 |
| 🤖 頭脳の切り替え | 右上で Haiku（普段使い）／Sonnet／Opus（じっくり）を選べる |

くわしい使い方は [`knowledge/パラスの使い方.md`](knowledge/パラスの使い方.md) にあります（パラス自身もこれを読んで答えます）。

## はじめかた

### 1. 最低限（会話だけ）
1. [Anthropic Console](https://console.anthropic.com/) で API キーを作る（利用料は従量課金。普段は安い Haiku を使います）
2. 公開ページを開き、右上の「設定」→「Anthropic APIキー」に貼り付けて保存
3. マイクを押して話しかける

声はブラウザ標準の読み上げでも動きます。

### 2. もっと使う（任意）
次の機能は、Cloudflare Workers に置く **中継サーバー**（`relay/fish-relay.js`）が必要です。秘密の鍵はブラウザに置かず、中継サーバーのシークレットにだけ置きます。

| 使いたい機能 | 必要なもの |
|---|---|
| Fish Audio の自然な声 | Fish Audio のキー |
| iPhone・iPad でのマイクの聞き取り | Fish Audio のキー（文字起こしは有料・ごく少額） |
| Google カレンダー・Gmail | Google Cloud の OAuth クライアント |
| お店の検索・経路案内 | Google Maps のキー（Places API (New)・Routes API） |
| 地図を Google マップで表示 | ブラウザ用の Maps JavaScript API キー（サイト制限つき） |
| 電車の乗り換え（任意・未使用） | RapidAPI の NAVITIME キー |

設置の手順は [`relay/README.md`](relay/README.md) にまとめています。設置後、パラスの設定の「中継サーバーのURL」に Worker の URL を入れます。

## 知識フォルダ（RAG）
`knowledge/` に Markdown・テキスト・PDF を置いて `main` に入れると、公開のたびに検索用の索引（`knowledge-index.json`）が自動で作られ、パラスがそれを調べて答えます。
- 趣味ごとにフォルダを分けると管理しやすい（例：`knowledge/コーヒー/`）
- 見出し（`#` `##`）をしっかり付けると、検索の精度が上がる
- **公開ページから誰でも読めるので、個人情報や社外秘は置かない**

くわしくは [`knowledge/README.md`](knowledge/README.md) を参照。

## 料金の目安
- **Anthropic API**：会話のぶんだけ従量課金。普段は Haiku、しばらく話さないと会話をリセットして料金を抑えます
- **Fish Audio**：声は無料モデル。iPhone・iPad の文字起こしはごく少額の有料
- **Google**：カレンダー・Gmail は無料。マップの検索・経路・表示は毎月の無料枠の範囲で使う想定（Google Cloud の「割り当て」で1日の上限を下げておくと安心）
- **Cloudflare Workers**：無料プランで足ります

## ファイル構成
```
index.html              アプリ本体（画面・会話・道具・音声・3D・背景。3Dモデルも埋め込み済み）
persona.md              パラスの人格設定（index.html の指示の読みやすい版）
manifest.webmanifest    PWA の設定
sw.js                   PWA のサービスワーカー（オフライン時の表示など）
icons/                  アプリのアイコン
assets/pallas_drone.glb パラスの3Dモデル（元データ）
knowledge/              パラスが調べる資料（RAG）
tools/build-knowledge.mjs  資料から検索用の索引を作るスクリプト
relay/                  中継サーバー（Cloudflare Workers）のコードと設置手順
.github/workflows/pages.yml  main に入ると GitHub Pages へ公開する
```

## 公開のしくみ
`main` ブランチに変更が入ると、GitHub Actions が次を行います。
1. アプリのファイルを公開用フォルダにまとめる
2. `knowledge/` から検索用の索引を作る
3. GitHub Pages に公開する

## データの保存場所
- 会話の履歴・記憶・タイマー・やること・設定・APIキーは、**使っている端末のブラウザの中**（localStorage）にだけ保存されます。端末やブラウザが違うと別々になります（例：Safari と、ホーム画面に追加したアプリは別）。
- サーバー側に会話は保存しません。
- 中継サーバーの鍵（Fish Audio・Google・RapidAPI）は Cloudflare のシークレットに置き、ブラウザには渡しません。
- Gmail はメールを送信しません（下書きの保存まで）。
